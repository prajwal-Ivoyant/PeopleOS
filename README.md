## 📌 Overview

**PeopleOS** is a modern web application designed to act as a
**centralized system for managing people, tasks, and workflows**.

It helps individuals and teams organize their work, track interactions,
and improve productivity --- all in one place.

Think of it as a **personal CRM + productivity OS**.

------------------------------------------------------------------------

## ✨ Features

-   👥 **People Management**
    -   Add, edit, and manage contacts
    -   Store important details and relationships
-   📋 **Task Tracking**
    -   Create and manage tasks
    -   Track progress efficiently
-   ⚡ **Modern UI/UX**
    -   Clean and responsive interface
    -   Fast and smooth interactions
-   🧠 **AI-Ready Architecture** *(future-ready)*
    -   Can integrate AI for suggestions, summaries, and automation
-   🗂️ **Organized Workflow**
    -   Structure your personal and professional life

## 🚀 Getting Started

### 1️⃣ Clone the repository

``` bash
git clone https://github.com/prajwal-Ivoyant/PeopleOS.git
cd PeopleOS
```

### 2️⃣ Install dependencies

``` bash
npm install
```

### 3️⃣ Run the development server

``` bash
npm run dev
```

### 4️⃣ Open in browser

http://localhost:5173
